Core Capabilities

  • AI Brain + Autonomous Agent: Direct HTTPS integration with Google Gemini & OpenRouter (Bangla & English), multi-step tool loop, and Android Keystore encrypted keys.
  • Local Virtual Linux Environment: Sandboxed virtual_env/ shell (/system/bin/sh), on-device Python 3 engine, Android V8 JS runtime, and localhost dev server.
  • Browser + Virtual Hands: Multi-tab WebView DOM automation + explicit Android Accessibility Service gestures & UI inspection.

Installation Instructions

  1. Download personal-ai-computer.apk above and verify its SHA-256 checksum.
  2. On your Android device (Android 7.0+), open the downloaded APK and grant Install unknown apps if prompted.
  3. Open AI Model Settings to add your own Gemini or OpenRouter API key.
  4. Optionally enable AI Computer Virtual Hands in Android Accessibility Settings.
