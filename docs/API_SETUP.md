# AI Provider & API Setup

1. Open **AI Model Settings** inside the app.
2. Enter your own **Google Gemini API Key** (from Google AI Studio) and/or **OpenRouter API Key** (from openrouter.ai).
3. Tap **Encrypt & Save** to store keys in Android Keystore.
4. Use **Discover** in OpenRouter Models to fetch live models and filter `[FREE]` models.
5. All requests go directly over HTTPS from your Android device to `generativelanguage.googleapis.com` or `openrouter.ai`.
